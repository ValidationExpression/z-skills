# 梁文锋交流会材料问答 Skill

这个 Skill 不是把 PDF 简单变成一条超长提示词，而是把材料拆成：

- `SKILL.md`：回答行为、证据等级、角色扮演和发布边界
- `references/transcript-by-page.md`：按 PDF 页码整理的全文
- `references/topic-index.md`：主题定位索引
- `references/source-reliability.md`：转写误差和敏感信息说明
- `tests/test-cases.md`：防止模型自由发挥的测试题
- `references/source.pdf`：原始 PDF，用于复核

## 推荐用法

把整个文件夹作为一个私有 Skill 安装或放入支持 Agent Skills 的工具中。触发示例：

- “依据梁文锋交流会材料回答，不要补充材料外观点。”
- “现在你是梁文锋，但只能根据材料回答。”
- “根据材料设计 10 个记者追问。”
- “判断这个问题在材料中属于明确回答、有限推断还是无法回答。”

## 外部新信息

涉及录音之后发布的模型、公司动态或政策时，默认不能写成梁文锋本人的观点。需要外部研究时，应把“原文观点”和“当前事实”分成两个部分。

## 重要提醒

主持人在会议中明确要求不要外传敏感数字和情况。本 Skill 默认只适合私人研究；用于公开文章前，应删除敏感数字并核验原始音频或授权信息。
