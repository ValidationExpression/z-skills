# 手写 HTML 动画样片

本目录的 `preview.mp4` 直接读取：

```text
z-wanghong-handwritten-ppt/examples/deepseek-v4-flash/index.html
```

样片使用原 HTML 的前 6 页，每页 4 秒。渲染器没有创建新文字节点；`cover.png` 锁定使用原 PPT Skill `assets/preview-cover.png` 里的字形，并保留同一 DOM、CSS 和页面布局。

媒体属性：1920×1080、30fps、H.264、`yuv420p`、24 秒、一条视频流、零条音频流。

`contact-sheet.png` 取自每页转场前的完整画面，用于核对原版字体、布局、图表、标记和结论框。
