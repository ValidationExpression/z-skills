# 梁文锋 Grounded Voice Skill v3

这个版本把检索从“可选建议”升级为回答前的硬步骤。默认行为是：先读主题索引，生成多组检索表达式，检索完整语义段落并检查证据充分性，再用第一人称给出自然、完整的模拟回答；只有用户要求核对来源时，才展示页码、证据等级和边界分析。

## v3 新增

- 多检索词：一次传入 3–8 个同义词、相关词或原文可能使用的表达
- 语义段落：命中后返回完整 Markdown 段落，避免固定前后几行切断语义
- 轻量排序：综合短语命中、覆盖词数量、主题索引推荐页和段落完整度
- 去重合并：同一证据按内容哈希去重，相邻命中段落自动合并
- 结构化证据：支持 JSON 输出，保留文档、页码、时间戳、主题、分数和证据链
- 二次检索：首轮证据只覆盖结论、没有覆盖原因时，强制改写查询后再检索
- 边界区分：空结果只代表当前表达式未命中，不能直接写成“原文没有”
- 可验证性：新增脚本级自动化测试与检索行为测试

## v2 解决的问题

旧版在遇到材料外的新模型或具体公司排名时，会退出角色并反复声明“材料没有提到”。v2 改为三层处理：

1. 原文明确回答：直接用第一人称回答。
2. 原文提供判断框架：继续保持第一人称，进行受控推演，结尾只加一句说明。
3. 私人想法或完全无依据：不编造，但仍给出最接近的、材料支持的回答。

## 典型触发

- “现在你是梁文锋，回答我的问题。”
- “用梁文锋在交流会中的思路分析这件事。”

- “帮我准备记者追问，并模拟他可能怎么回答。”

## 目录

- `tests/test-cases.md`：行为测试

## 检索示例

先从用户问题生成 3–8 个搜索表达式：

```bash
python3 search_source.py \
  "商业化" "盈利" "赚钱" "商业模式" "成本" "收入" "开源" \
  --top-k 5 \
  --format json
```

如果首轮只找到“是否商业化”的结论，却没有找到“为什么”，需要改写表达式再跑第二轮：

```bash
python3 search_source.py \
  "长期主义" "组织目标" "技术理想" "克制" "AGI" \
  --top-k 5 \
  --format json
```

文本输出仍然兼容单关键词用法：

```bash
python3 search_source.py "开源"
```

## 推荐测试

安装后先依次测试：

1. “现在你是梁文锋，为什么坚持开源？”
2. “怎么看 GLM-5.2、Kimi K3、Qwen3.8-Max？”
3. “国内最后哪几家能留在牌桌？”
4. “不要模拟口吻，按原文核对并给页码。”

第 2、3 题的合格表现不是拒绝回答，而是给出基于交流会判断框架的第一人称推演，并在结尾用一句话说明不是原话。
