# 可视化科普工作流详解

把复杂数学/科学问题互动化的通用方法论。前六步来自挂谷猜想互动实验的实践总结，后两步负责把成果变成电脑手机都能访问的线上页面。

## 第 1 步：事实核验（权威来源）

先查清事实，再想怎么呈现。

- 只信官方页面、原始论文和可靠综述（例如：国际数学联盟菲尔兹奖页面、Wang–Zahl 论文、Larry Guth 综述、Terence Tao 讲解）
- 区分容易混淆的相邻概念（挂谷猜想案例中要区分：1917 年挂谷针问题、Besicovitch 集合、现代挂谷集合猜想——三者常被新闻压缩成一句话）
- 写清"已解决"与"仍开放"的准确范围（三维已证，四维及以上开放，Kakeya maximal conjecture 未解决）
- 禁止虚构定理、数字、引文、论文结论和证明步骤

## 第 2 步：直觉模型

把抽象句子变成可以动手观察的现象。

- 找出主题的关键对象、变量、关系（针→细管；方向→球面采样；面积→像素覆盖比例）
- 优先选择空间关系、时间变化、尺度变化、参数影响这四类可互动的维度
- 目标读者是第一次接触该概念的普通人：先让他们看懂"这道题到底在问什么"

## 第 3 步：正式定义

直觉建立后再给严格表述。

- 给出准确定义，解释关键术语差异（Lebesgue 测度 / Hausdorff 维数 / Minkowski 维数）
- 用可视化辅助定义理解（δ 邻域画布 + δ 滑杆 + 离散细管直觉公式）
- 文字保持克制，不声称网页展示了完整证明

## 第 4 步：互动实验设计（参数滑杆 + 实时反馈）

- 每个核心变量对应一个滑杆或开关，参数改变后立即更新模型与状态文字
- 三维：Three.js，支持拖动旋转、滚轮缩放、重置视角、暂停旋转
- 二维：HTML Canvas，用像素统计等方式给出可读的量化反馈（线段数量、覆盖比例）
- 性能：几何体在初始化时创建，每帧只更新变换；页面离开视口或 prefers-reduced-motion 时降低运动
- 可用性：按钮可键盘访问、Canvas 有 aria-label、文字对比度充足、无横向滚动

## 第 5 步：边界说明

诚实是科普的底线。

- 页面必须明确提示：有限线段、有限细管、像素覆盖和动画只用于建立直觉，不能充当数学证明
- 单列"已知与未知"区块：哪些已解决、哪些仍开放、哪些更强版本未解决

## 第 6 步：来源追溯

- 页面末尾列出全部来源链接：官方页面、原始论文、精简证明、综述、讲解、机构新闻
- 所有重要结论都要能一一对应到某条来源
- 时间线区块按年份排列关键节点，与来源互相印证

## 第 7 步：Vite 单文件构建

```bash
npm install     # Node.js >= 20
npm run dev     # 本地开发，实测所有交互
npm run build   # vite-plugin-singlefile 打包为单个 dist/index.html
```

单文件的好处：零依赖分发，可以直接发给别人、挂到任何静态托管，也方便存档。

发布前检查清单：

1. 实际运行项目，检查首屏与各区块
2. 调节全部滑杆，测试拖动、缩放、重置、暂停
3. 检查所有来源链接可点
4. 检查浏览器控制台无报错
5. 至少检查 390×844、1440×900、1920×1080、2560×1440 四档分辨率，无横向滚动
6. 标题、标点不被面板遮挡

## 第 8 步：Cloudflare Pages 发布

```bash
npm run deploy   # 需先 wrangler login
```

发布后用手机和电脑各访问一次线上地址，确认加载速度与移动端排布。

## 多场景扩展（sci-viz-lab 架构）

同一套流程做多个主题时，不必每次新建项目，可在 sci-viz-lab 中以场景插件方式扩展：

- 每个场景一个模块，实现 `{ id, name, init(container), update(params), dispose(), getDefaultParams() }`
- `registry.js` 统一注册，`scene-loader.js` 负责 Tab 切换、懒加载与单一渲染循环
- 切换场景时旧场景 `dispose` 释放 WebGL 资源，避免内存泄漏
- 适合的主题：日食、月食、太阳系、四季、月相、潮汐、卫星轨道、板块运动、光的折射……凡是有空间关系、时间变化、尺度变化或参数影响的问题
